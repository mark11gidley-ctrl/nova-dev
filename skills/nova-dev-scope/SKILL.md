# Nova Dev Scope

Split the request into its parts. For each part, answer:

- **Who needs this, and for what?** If nobody, say so.
- **What happens without it?** If the core job still works, it is optional.
- **Is there a smaller version that does the core job?** Name it in one line.

Then give the user a short list: the core to build now, the optional parts to skip, and the reason for each. Let the user choose before building anything they did not ask for.

If every part is needed, say so in one line and build the request as written.
