# Nova Dev Changelog

1. Find the changelog (`CHANGELOG.md`, `HISTORY.md`, `docs/changelog`). If there is none, say so and stop; do not create one unless asked.
2. Match its format exactly: heading style, section names (Added, Changed, Fixed, Removed), date and version style.
3. Write one entry per user-visible change, in plain words, under the unreleased or next section.
4. Skip internal refactors unless they change behavior.

Show the entry before writing it to the file.
